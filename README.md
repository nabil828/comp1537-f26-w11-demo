# COMP 1537 — Week 11 Demo: Pokémon App

Live lecture demo of the Week 11 tutorial: a single Express server serving a Pokémon list ([PokéAPI](https://pokeapi.co/)), with session-based login and a per-user favorites list.

Hardcoded users: `ash`/`pikachu`, `misty`/`starmie`, `brock`/`onix`.

## Run locally

```sh
npm install
node server.js
```

Then open `http://localhost:3000`.
